# MW4 Camo Grind Tracker

A small personal tracker for the camo grind in Call of Duty: Modern Warfare 4 (Multiplayer).
Tick off Gold, Platinum and Harmonic Break per weapon, follow Divergence and the Mastery camos.
Progress is saved in your own browser only; nothing is sent anywhere.

Built with SvelteKit (static site, no server). Every push to `main` is published to GitHub Pages.

```bash
npm ci
npm run dev
```
